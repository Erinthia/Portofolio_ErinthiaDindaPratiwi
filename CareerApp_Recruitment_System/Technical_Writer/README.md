# 📘 Technical Writer — CareerApp Recruitment System

Folder ini berisi dokumentasi lengkap sistem **CareerApp Recruitment System** 
yang disusun dalam peran sebagai **Technical Writer**.  
Dokumentasi ini bertujuan untuk memberikan panduan penggunaan, pemahaman fitur, 
serta referensi teknis bagi pengguna dan tim internal.

---

## 📂 Daftar Dokumen

+ **1. Dokumentasi Pengguna & Sistem**
   - Dokumentasi CareerApp.pdf

   Dokumen ini mencakup:
   - Deskripsi sistem dan tujuan pengembangan
   - Gambaran fitur utama (CV Screening, Psikotes, Interview HR/User, Offering)
   - Penjelasan role (Super Admin, Admin, Staff, Pelamar)
   - Panduan penggunaan tiap fitur (step-by-step)
   - Tampilan antarmuka (UI Preview)
   - Alur proses sistem
   - Penjelasan input & output
   - Instruksi umum untuk troubleshooting

   Dokumen dibuat dengan bahasa yang jelas, terstruktur, dan mudah dipahami untuk mendukung pengguna dalam mengoperasikan sistem secara mandiri.

---

## 🎯 Tujuan Folder Technical Writer
Dokumen ini disusun untuk:
- Menyediakan panduan resmi penggunaan sistem CareerApp  
- Mendukung onboarding pengguna baru  
- Menjadi referensi teknis bagi tim internal (developer, QA, analis)  
- Menjaga konsistensi pemahaman terhadap fitur dan alur sistem  

---

## 📎 Catatan
Dokumen ini merupakan bagian dari portofolio profesional sebagai **Technical Writer** dan dibuat berdasarkan fitur yang dikembangkan selama proyek **CareerApp Recruitment System**.
