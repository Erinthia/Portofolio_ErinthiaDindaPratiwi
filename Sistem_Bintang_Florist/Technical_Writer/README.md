# 📘 Technical Writer — Sistem Bintang Florist

Folder ini berisi dokumentasi resmi untuk **Sistem Bintang Florist**,  
yang disusun dalam peran sebagai **Technical Writer**.  
Dokumen dibuat untuk membantu pengguna memahami alur sistem, fungsi utama, serta cara menggunakan fitur dengan benar.

---

## 📂 Daftar Dokumen

+ **1. Dokumentasi Sistem**
   - Dokumentasi BintangFlorist.pdf

   Isi dokumen mencakup:
   - Deskripsi umum sistem
   - Fitur utama & penjelasan per modul
   - Alur proses untuk setiap role
   - Preview tampilan antarmuka (UI)
   - Input, output, dan ketentuan penggunaan
   - Penjelasan menu dan fungsi sistem
   - Cara operasional dasar untuk pengguna

   Dokumen ini menjadi panduan utama untuk memahami keseluruhan cara kerja sistem Bintang Florist.

---

+ **2. Panduan Operasional (Change & Delete Users)**
   - Panduan Change dan Delete Users Sistem Bintang Florist.pdf

   Dokumen ini berisi prosedur detail mengenai:
   - Cara mengubah data pengguna
   - Cara menghapus data pengguna
   - Ketentuan yang harus diperhatikan sebelum melakukan perubahan data
   - Validasi umum dan pesan error yang mungkin muncul
   - Tujuan dan batasan fitur

   Panduan ini dibuat secara ringkas dan step-by-step agar mudah diikuti oleh admin atau staff yang menggunakan sistem.

---

## 🎯 Tujuan Folder Technical Writer
Tujuan penyusunan dokumentasi ini antara lain:
- Mendukung pemahaman pengguna terhadap fitur sistem  
- Menjadi acuan resmi bagi admin dan karyawan  
- Menjaga konsistensi penggunaan sistem dalam operasional  
- Memberikan referensi yang mudah dipahami dan terstruktur  

---

## 📎 Catatan
Dokumen ini merupakan bagian dari portofolio profesional sebagai **Technical Writer**, disusun berdasarkan fitur dan kebutuhan operasional **Sistem Bintang Florist**.
