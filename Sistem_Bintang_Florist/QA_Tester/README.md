# 🧪 QA Tester (Manual) — Sistem Bintang Florist

Folder ini berisi artefak pengujian manual untuk **Sistem Bintang Florist**,  
yang dilakukan dalam peran sebagai **QA Manual Tester**.  
Dokumen ini memuat skenario uji, langkah uji, hasil uji, serta validasi terhadap fungsi-fungsi utama sistem.

---

## 📂 Daftar Dokumen

+ **1. Manual Testing Document**
   - Manual Testing Bintang Florist.pdf

   Dokumen ini berisi:
   - Test scenario & test case
   - Expected vs Actual Result
   - Status pengujian (Pass/Fail)
   - Catatan bug & rekomendasi perbaikan
   - Screen Capture

   Pengujian dilakukan untuk memastikan seluruh fitur berjalan sesuai kebutuhan dan bebas dari kesalahan fungsional.

---

## 🔍 Fokus Pengujian
Pengujian manual ini mencakup beberapa fitur utama, antara lain:
- Manajemen produk
- Manajemen pesanan
- Manajemen pelanggan
- Dashboard admin
- Otentikasi & otorisasi pengguna
- Validasi form & input pengguna
- Alur transaksi pada sistem Bintang Florist

---

## 🎯 Tujuan Folder QA Tester
Dokumen ini dibuat untuk:
- Menunjukkan kemampuan dalam melakukan manual testing end-to-end  
- Mengidentifikasi bug, inkonsistensi, dan risiko pada sistem  
- Memberikan laporan QA yang terstruktur bagi tim developer  
- Menjadi bukti kompetensi pengujian sebagai QA Manual Tester  

---

## 📎 Catatan
Dokumen ini merupakan bagian dari portofolio profesional di bidang **Quality Assurance (Manual Testing)**.  
Semua hasil pengujian dilakukan berdasarkan fitur dan alur pada **Sistem Bintang Florist**.
